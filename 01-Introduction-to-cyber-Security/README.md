## Module 1: Introduction to Cyber Security

### 1. Offensive Security

Offensive security focuses on thinking like an attacker to identify weaknesses in systems and applications before malicious attackers can exploit them. This includes areas such as penetration testing, ethical hacking, and red teaming.

### 2. Defensive Security

Defensive security focuses on protecting systems, detecting threats, and responding to security incidents. Key areas include:

* **SOC (Security Operations Center)** — monitoring and investigating security events
* **DFIR (Digital Forensics & Incident Response)** — investigating incidents and responding to security breaches
* **Threat Intelligence** — collecting and analysing information about threats and attackers


### 3. Careers in Cyber Security

Cyber security offers a wide range of career paths, including both technical and non-technical roles.

Some roles introduced include:

* Penetration Tester
* SOC Analyst
* Security Analyst
* Incident Responder
* Threat Intelligence Analyst
* Digital Forensics Analyst
* Malware Analyst
* Security Consultant

**Key takeaway:** Cyber security is a broad field, and there are different career paths depending on your interests and skills.

### Key Takeaways

* Offensive security focuses on identifying and testing weaknesses.
* Defensive security focuses on protecting systems and responding to threats.
* Understanding how attackers operate can help defenders improve security.
* Cyber security is a broad field with many different career paths.
