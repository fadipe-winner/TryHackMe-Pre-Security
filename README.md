# TryHackMe Pre Security Learning Journey

## Overview

This repository documents my learning journey through the **TryHackMe Pre Security learning path**.

I created this repository to reinforce what I learned by documenting key concepts in my own words, keeping a record of my progress, and building a foundation that I can continue to develop as I progress in cybersecurity.

Rather than focusing only on completing the learning path, I used the documentation process to revisit concepts I found challenging and improve my understanding through further practice.

---

## Modules Completed

### 1. Introduction to Cyber Security
An introduction to cybersecurity, including the roles of offensive and defensive security and how they contribute to protecting systems and information.

### 2. Computer Fundamentals
Covered the basic components of computer systems, how computers process information, and foundational concepts needed to understand how systems operate.

### 3. Operating System Basics
Developed a better understanding of Windows and Linux, including operating system components, users, processes, permissions, system information, and command-line navigation.

### 4. Software Basics
Introduced data representation and programming fundamentals using Python, JavaScript, databases, and SQL.

This module helped me better understand variables, conditions, loops, user input, programming logic, and querying structured data.

### 5. Networking Fundamentals
Covered how devices communicate across networks, including:

- IP and MAC addresses
- TCP and UDP
- DNS and DHCP
- ARP
- Common ports and protocols
- OSI and TCP/IP models
- Routers and switches
- Firewalls and VPNs

This module helped me understand the foundations of network communication and why understanding normal network activity is important when investigating security events.

### 6. Web Fundamentals
Explored how websites and web communication work, including:

- DNS
- HTTP and HTTPS
- URLs
- HTTP requests and responses
- Methods and status codes
- Headers and cookies
- Front-end and back-end technologies
- Web servers

This provided a stronger foundation for understanding web traffic and web-related security concepts.

### 7. Attack and Defense Fundamentals
Introduced core cybersecurity concepts including:

- The CIA Triad
- Cryptography
- Symmetric and asymmetric encryption
- Hashing
- Vulnerabilities and exploits
- Authentication and credentials
- Enumeration
- Basic offensive and defensive security concepts

This module also helped me understand the importance of examining multiple pieces of evidence before deciding whether activity is malicious.

## My Approach

One of my main goals throughout this learning path was to focus on **understanding rather than simply completing rooms**.

When I encountered concepts I did not fully understand, I revisited them, practiced with examples, and documented what I learned.

This repository serves both as a record of that process and as a reference that I can continue to revisit as my cybersecurity knowledge develops.
